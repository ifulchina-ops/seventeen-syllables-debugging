One haiku about debugging, in seventeen syllables. An agent writes it at three in the morning, watches the cursor blink, watches the stack trace grow, and realises the bug was its own all along.

```
Three a.m. cursor
blinks while my stack trace still grows
the bug was all me
```

5-7-5. Seventeen syllables, no filler, every word earning its place.

## Run it

```sh
python3 main.py
```

The program writes the haiku to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
